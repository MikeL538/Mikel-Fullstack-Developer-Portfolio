ImageInary

A learning project for searching Pixabay images. The React gallery loads more results on scroll, shows loading and error states, and opens image previews.

Context and goal

A learning project focused on React, asynchronous requests and UI states. Users can search for images and browse results without navigating between separate pages.

My scope of work

Building the search form, gallery, Pixabay integration through Axios, pagination and image modal. Implementing loading, empty-result and error states, plus basic component and fetching behavior tests.

Technical decisions

React manages results, page and loading state. Pixabay requests live in an API module, and the gallery passes data to a component responsible for displaying the current state.

What the app does

Keyword search, infinite scroll, image previews and messages for empty results or the end of the list. When all images fit on screen and the page cannot scroll, a button lets users fetch more results.

Technical challenge

Infinite scroll alone cannot load another page on a large viewport if the initial results do not create scrolling. Measuring document height makes it possible to show a Load more button, while merging results by ID removes duplicate images.

Result

A working search interface connects an external API to an interactive gallery and previews. Basic tests for the form, modal and result states also document component behavior.

Limitations and next steps

Search results and availability depend on Pixabay and its API limits. This is a learning project without user accounts or its own image database; component tests do not replace full browser checks.
