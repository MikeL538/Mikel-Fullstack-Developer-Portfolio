Formularz Zjazd SLO

Registration for a real SLO alumni reunion in Żary. The form sends submissions to Supabase, while organizers use a separate admin application.

Context and goal

Organizers of the Social High School alumni reunion in Żary needed a public event website and a shared place to collect attendee registrations.

My scope of work

Building the event page, responsive form and JavaScript integration with Supabase. The public app covers validation, consent handling, submission, result messages and a public attendee list. The organizer panel is a separate application.

Technical decisions

The public site remains a straightforward HTML, SCSS and JavaScript application. The form sends data to the Supabase submit-guest function. The attendee list reads graduation years and display names from people_public rather than retrieving full contact details.

What the app does

Attendees provide contact information and a graduation year, with optional notes, education and work fields. The form checks required values, consent and a CAPTCHA token. Successful registration refreshes the attendee list.

Technical challenge

Registration collection, public attendee display and organizer workflows needed distinct responsibilities. The interface uses separate endpoints for submission and public reads, while full registrations are handled in a separate panel.

Result

A workflow from event information through a validated form to registration storage in Supabase. Organizers can work with submissions without placing administrative functions on the public website.

Limitations and next steps

The public URL serves real event registrations. Submission depends on the Supabase function and CAPTCHA; access to full records requires the separate panel and appropriate database permissions.
