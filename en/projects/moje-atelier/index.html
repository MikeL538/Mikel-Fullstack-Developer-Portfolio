Moje Atelier

A psychology practice website with services, pricing and appointment requests. The interface and features are ready; the demo awaits the client's final content.

Context and goal

The Moje Atelier psychology practice in Żary needs a place where visitors can explore services, prepare for a first visit and submit preferred consultation dates.

My scope of work

Building the responsive React interface, SCSS styles, service and pricing pages, and appointment request form. The scope includes validation, request delivery API integration, HTML prerendering, metadata and configuration of the Vercel demo.

Technical decisions

Shared service data feeds the price list and form to keep names, prices and durations consistent. Prerendering provides content in the initial HTML while React handles interactions. Requests are delivered through an API, outside the browser code.

What the app does

Visitors select a service, provide contact details and suggest up to three dates with preferred times. The form communicates validation errors, sending progress and the result. Submission requests a visit; the practice confirms the appointment separately.

Technical challenge

The form needs to retain input after delivery errors and limit duplicate submissions. A sending state prevents repeated clicks, while a request identifier allows the API to recognize a retry. Validation errors direct users to the relevant fields.

Result

A functional interface, request handling and pages prepared for publication. The demo presents the layout and available features, with content configuration separated from components.

Limitations and next steps

The project is still in progress pending the client's information, photos and copy. Pricing and practice details require final approval. The demo does not represent the practice's final website launch, and submission does not automatically reserve a time slot.
